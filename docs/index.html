dshe~

Send files between machines. No cloud, no accounts, no cables.

Download latest Source on GitHub

quickstart

# machine A — sender (announces itself on the LAN)
$ dshe send myfolder
imported folder (compressed) myfolder (977.14 KiB)

  dshe receive blobav3vanxqbcbyn7a46lqimpk47utzp7wnuu...

# machine B — receiver. no ticket? just scan the LAN:
$ dshe receive --scan
fetching 1 file (488.70 KiB)
  downloading [██████████████░░░░░░] 45.2 MiB/190.7 MiB (7s left)
received myfolder (977.14 KiB) in 3s

why dshe

verified streaming

Every chunk is verified against a blake3 hash baked into the ticket. Corrupted or tampered data is mathematically impossible to miss.

p2p, encrypted

Direct connections with NAT hole punching over QUIC. Relay fallback when the network is hostile. End-to-end encrypted either way.

SHAREit-style discovery

Senders announce themselves on the LAN. dshe receive --scan lists them. No ticket needed — works with the router unplugged.

one-shot by default

The sender exits on its own after the first receiver completes. --nostop serves forever, --bg runs in the background.

folders, compressed

Directories are packed into a single tar.gz, sent as one blob, and unpacked on the other side. --noarchive to skip.

small & fast

A ~4 MB static binary per platform. No runtime, no dependencies, no installer.

flags you'll actually use

--scandiscover nearby senders and pick one
--qrshow the receive command as a scannable QR code
--bg / --bg-stopserve in the background (forever / until first transfer)
--noarchivesend folders uncompressed
--nostopkeep the sender alive for multiple receivers
--resumekeep partial downloads so a retry can continue
--relay disabledLAN-only mode, fully offline

the dead-router recipe

Internet's gone, router's off, someone's in the same room:

# turn on a phone hotspot, both machines join it, then:
$ dshe send --qr ./stuff
# ...point your phone at the screen, done.

dashe is a fork-flavored rewrite of the excellent sendme, built on iroh.
