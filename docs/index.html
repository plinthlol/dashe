send files.
skip the cloud.

p2p file transfer between machines over LAN or the internet. encrypted end-to-end, blake3-verified, no cloud, no accounts. one ~4 MB binary.

quickstart

# machine a — sender
$ dshe send myfolder
imported folder (compressed) myfolder (977.14 KiB)

# machine b — receiver. no ticket needed:
$ dshe receive --scan
  downloading [██████████████░░░░░░] 45.2 MiB/190.7 MiB (7s left)
received myfolder (977.14 KiB) in 3s

how it works

  • senders announce — a tiny beacon on the local network, every second. no server, no internet.
  • receivers pick — receive --scan lists everyone sharing nearby. tap a number.
  • data moves p2p — direct connection (nat hole punching) over quic, relay fallback if the network is hostile.
  • everything is verified — every chunk checked against a blake3 hash. corruption or tampering fails, always.

flags

--scandiscover nearby senders, pick one interactively
--qrshow the receive command as a scannable qr code
--bg / --bg-stopserve in the background (forever / until first transfer)
--nostopkeep serving for multiple receivers
--noarchivesend folders uncompressed
--resumekeep partial downloads so a retry continues
--relay disabledlan-only mode, fully offline
--debughash, per-file listing, transfer speed
completionsprint shell completions (zsh, fish, nushell)

the dead-router recipe

# turn on a phone hotspot. both machines join it. then:
